# Интерактивный просмотр модели

3D-просмотр атриума арт-школы в браузере.

- Маршрут длительностью 60 секунд с запуском, паузой и выбором момента.
- План здания с текущей позицией камеры.
- Нейтральный режим и цветовое выделение категорий.
- Экспорт кадров в PNG ZIP.

Вся модель и библиотеки встроены в `index.html`; серверная часть и внешние CDN не требуются. Для 3D нужен браузер с поддержкой WebGL.

GitHub Pages: ветка `main`, папка `/` (root).

Демонстрация показывает движение по заданному маршруту.
